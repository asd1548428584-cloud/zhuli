# reports/ — 批次报告归档（只放最新版）

本目录是 zhuli 项目**所有批次审查 / 核验 / 审计报告的唯一定稿位置**。
产品设计文档仍在 `zhuli/lastchat/docs/`，本目录只放"过程报告"。

## 归档规则

1. **一个报告一个文件，只保留最新版。** 同一份报告被修订时，**覆盖同名文件**，不新建 `-v2`、`-final`、`-20261128` 之类的日期副本；历史版本由 Git 提交历史保存，可随时 `git log -p` 取回。
2. **文件名 = `批次号_主题.md`**，批次号在前（`C1-B_` / `C1-B1_`），便于按批次排序。
3. **附件与主报告同目录**，文件名带"附件"或在索引表里标注"附件"，避免被当成独立结论。
4. 新增或修订报告后，**必须同步更新本 README 的索引表**（结论、日期、关联提交）。

## 禁止入本目录的内容

以下材料属用户隐私或本机环境，**永不入库**（`.gitignore` 已封堵同类）：

- `Temp/` 下的真实数据库副本（`*.db`）、短信 / 通知原文、取件码、地址；
- 真机取证截图、UI dump、`fixtures/realdev_*`、`session-*.jsonl`；
- 任何密钥、令牌、口令、keystore。

报告里引用真实库时，**只写路径、大小、SHA-256 与聚合统计**，不贴数据行原文。
