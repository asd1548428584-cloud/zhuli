## 1. 安装 Android Studio（一次性，约 20–40 分钟看网速）

1. 浏览器打开上表地址，下载 `android-studio-*-exe`（约 1GB），双击 → 一路默认下一步，装到英文路径（如 `C:\AndroidStudio`，避免中文/空格路径）
2. 首次启动选 Standard；自动下载 SDK Components（几百 MB）
3. 全部完成后左下角 `More Actions → SDK Manager`，确认勾选：
   - **Android 15 (API 35)**（compileSdk=35 需要）
   - **Android SDK Platform-Tools**（含 adb）、**Build-Tools**
4. `More Actions → Device Manager` 留着，后面插手机用

## 2. 努比亚 Z70 Ultra 开 USB 调试（Nebula AIOS / MyOS）

1. 手机 **设置 → 关于手机**，连续点击 **「系统版本」**（或「版本信息」）7 次，提示「已进入开发者模式」
2. 返回 **设置** 首页搜索框输入 **「开发者」**，进入 **开发者选项**
3. 打开 **「USB 调试」**，用数据线连电脑，手机弹窗 **「允许 USB 调试」点确定**
4. （可选）同一 Wi-Fi 下也可用「无线调试」配对免线运行，下面同样生效

## 3. 链路验证

- AS 顶部菜单 `View → Tool Windows → Terminal`（或单独 cmd），输入：
  ```bat
  adb devices
  ```
- 期望输出类似：
  ```
  List of devices attached
  XXXXXXXXXXXX    device
  ```
- 若显示 `unauthorized`：拔线重插，手机上重新点「允许」；仍不行回开发者选项关-开 USB 调试

## 4. 打开并构建本项目（zhuli-assistant-step2-build）

**两条路任选其一：**

### 路线甲：轻量命令行工具链（本鱼已实际跑通，推荐先看）

已在本机 `D:\zhuli-dev` 落地（D 盘余 80GB）：JDK17 + Android cmdline-tools + SDK(platform-tools / android-35 / build-tools 35.0.0) + Gradle 8.11.1。命令：

```bat
set JAVA_HOME=D:\zhuli-dev\jdk-17.0.21+9
cd C:\gzq\zhuli\zhuli-assistant-step2-build
D:\zhuli-dev\gradle-8.11.1\bin\gradle.bat --no-daemon assembleDebug
```

产物：`app\build\outputs\apk\debug\app-debug.apk`

踩坑备忘：
- build-tools 必须钉死 35.0.0（AGP 8.7.3 默认找 34，会触发自动下载撞墙）：已在 `app/build.gradle.kts` 加 `buildToolsVersion = "35.0.0"`
- 依赖走阿里云镜像（`settings.gradle.kts` 已内置）
- 若 sdkmanager 报许可未接受：先 `(for i in 1..20; do printf 'y\n'; done) | sdkmanager --licenses` 再装包

### 路线乙：Android Studio 图形界面

1. AS：`File → Open`，选择 **`C:\gzq\zhuli\zhuli-assistant-step2-build`**
2. 弹窗 `Trust Project?` 点 Trust；无 wrapper 时 AS 会提示生成 Gradle Wrapper，选同意
3. 等 Sync 完成（依赖从阿里云镜像拉，Google/central 原站作兜底）
   - **坑①**：若 Sync 卡在下载 Gradle 发行包超时 → 打开 `gradle/wrapper/gradle-wrapper.properties`，把 `distributionUrl` 改为
     `https\://mirrors.cloud.tencent.com/gradle/gradle-8.11.1-bin.zip`
   - **坑②**：报 `Failed to find target with hash string 'android-35'` → SDK Manager 勾选安装 Android 15 (API 35)
   - **坑③**：报 `Failed to install build-tools;34.0.0 ... licences` → 本工程已钉 35.0.0，若仍报错确认未覆盖 `app/build.gradle.kts` 的 `buildToolsVersion`
4. 点击顶部绿色 **Run ▶**，选择你的 Z70 Ultra 设备名，等 Build & Install，App 自动打开主界面

## 5. 五步真机验收（对应 step2 README 第 2 步验收标准）

| # | 动作 | 通过标准 |
|---|---|---|
| 1 | App 内点「打开通知使用权设置」，开开关并勾选本 App，回通知 |
| 2 | 任意 App（如微信/淘宝）弹一条通知 | 主界面「最近 10 条」出现一条 `source=notification` 记录 |
| 3 | 其他 App → 分享文字 → 选「zhuli助理」 | 收到「已收下」回执；「最近 10 条」出现 `source=share` 记录 |
| 4 | 搜之前发过的中文字（≥3 字） | 搜索结果命中（FTS5 trigram）；搜不到说明触发 LIKE 降级，也算通过 |
| 5 | 彻底杀掉 App 进程，重启 | 监听服务重新绑定，之前数据不丢 |

## 6. 故障速查表

| 现象 | 处置 |
|---|---|
| `adb devices` 为空 | 数据线换一根（只充电线不成）；手机开「USB 调试」并授权 |
| 通知一条不进来 | 系统「通知使用权」未开（第 1 步）；或来源 App 被系统免打扰/置顶屏蔽了预览文本 |
| 分享菜单没有助理 | 系统分享面板刷新；确认装了刚构建的 APK（分享目标随 APK 注册） |
| 中文检索不灵 | 自动降级 LIKE 已兜底；FTS 需 API 35+，minSdk 24 无碍 |
| Build 红字 `Could not resolve` | 开代理/换网络再 Sync；或临时在 AS 设置里换 HTTP Proxy |
| MyOS 后台杀进程 | 第 13 步专项处理（B4 白名单），先手动把本 App 加入自启动白名单临时顶住 |
