## 一句话

**把手机上到处流的信息收进一个本地库，理解它、到点提醒你、并且问得出来**——
不是又一个聊天框，而是一个"替你记事、替你盯着"的助手。

## 为什么做这个

一个人每天要处理的琐事，其实撒在七八个地方：

- 微信群里有人说「周三下午三点评审」，翻聊天记录能找到，但**到点会忘**
- 快递到驿站了，短信躺在通知栏里，**三天后才想起来**
- 这个月花了多少，得掰着手指从支付记录里加
- 领导随口说的「下周给我」，当时记了一下，**后来不知道记哪儿了**

市面上的方案要么靠你手动记（笔记 App），要么把数据全传到别人服务器（各种 AI 助手）。
这个项目选第三条路：**能用 AI，但东西不出机**。

## 它怎么工作

```
   输入                   理解                    存储                输出
┌──────────────┐   ┌──────────────┐   ┌──────────────┐   ┌──────────────┐
│ 通知监听      │   │ 规则提取      │   │ SQLite v11   │   │ 准点提醒      │
│ 分享菜单      │──▶│ 分类/时间/金额│──▶│ 收件 / 提醒   │──▶│ 晨间简报      │
│ 链接正文      │   │ 快递取件码    │   │ 账本 / 聊天   │   │ 桌面小组件    │
│ 图片 OCR      │   │ 周期规则      │   │ 出网留档      │   │ 对话问答      │
│ 语音/视频     │   ├──────────────┤   │ 向量(256维)   │   ├──────────────┤
│ 短信(快递)    │   │ 模型工具调用  │   └──────────────┘   │ 单步点屏幕    │
└──────────────┘   └──────────────┘                       │ 到家用提醒    │
                                                          └──────────────┘
```

**两套理解并行**，谁合适用谁：

- **规则**：分类、抓时间、抓金额、认快递取件码、算周期——毫秒级、离线、结果可预期
- **模型**：听不懂的话、要组织的回答、要决定"查什么"的时候，走工具调用

模型不是"聊天机器人"，它手里有 6 个工具：查记忆 / 列待办 / 账本小结 / 查快递 / 建提醒 / 存备忘。
**它只能通过工具看你的数据，工具返回什么它就说什么，编不出来。**

## 能做什么

| 类别 | 具体能力 |
|---|---|
| **收** | 通知（含群聊）、分享文字/图片/视频/语音、链接正文、快递短信 |
| **懂** | 十类分类、时间解析（含"下周三""明天下午三点"）、金额与记账、快递承运商+驿站+取件码、周期规则（每天/每周/每月） |
| **记** | 本地记忆库 + 全文检索 + 向量混合检索；账本；聊天记录 |
| **提** | 准点提醒（偏差 0 秒）、完成/稍后、周期自动顺延、误点可撤回、晨间简报（周一加周报） |
| **问** | "这周花了多少""接下来有什么事""我的快递到了吗""上次那个门市叫啥""记住我的工号是 A8823" |
| **动** | 写系统日历、桌面小组件、长按快捷指令、到家用/到公司提醒取快递、单步点击屏幕 |
| **护** | 敏感闸门、出网留档（可查我发了什么）、API Key 加密存储、App 锁、加密备份、CSV/JSON 导出 |

## 三条不肯让的原则

1. **本地优先**：能本地算的绝不联网。规则算不了的才找模型；找模型时，
   非敏感原样发、敏感**先脱敏**、证件号/卡号/验证码**脱敏也不发**。
2. **只收不发**：不代你发消息、不代你付款、不批量点屏幕。屏幕操作只做"你确认后点一下"。
3. **可解释、可回查**：每次上云都留一条脱敏摘要（App 内「出网记录」）；
   每条提醒都能追溯到哪条原始消息；数据随时能导出带走。

## 技术上是什么

- **逻辑层**：纯 Kotlin（`core/`，41 个文件，无 UI 依赖），可整体搬进任何 Android 宿主
- **验收壳**：一个极简 App（单页 + 若干面板），只为把能力跑起来做验收
- **存储**：SQLite v11，7 张表（收件 / 提醒 / 账本 / 聊天 / 出网留档 / 技能 / 向量）
- **依赖**：AndroidX + ML Kit 中文 OCR（bundled，**不依赖 Google Play 服务**）+ 系统 API
- **云端**：任何 OpenAI 兼容端点（当前用基元律动 `qwen3.8-flash`），Key 只存手机 Keystore
- **目标机**：努比亚 Z70 Ultra（MyOS / Android 15，无 GMS）

## 诚实的边界

- **规则覆盖有限**：纯规则时代 227 条收件里 84% 归"其他"，接上模型工具调用后才有实质改善；
  换个说法的问法、需要推理的问题，仍可能答不好
- **语音还不能本地转写**：本机没有可用的识别服务，模型能下但缺运行时；现在依赖云端且需手动开
- **视频只做抽帧 OCR**：不做逐帧理解，音轨转写没接
- **整库还没加密**：只有 App 锁 + 备份加密，数据库文件本身是明文（换机/换电脑前建议先「加密备份」）
- **无障碍能力有天然限制**：网页、游戏、以及银行类 App 读不到也点不了

## 和同类比，它的位置

| | 商业 AI 助手 | 笔记/待办 App | **本项目** |
|---|---|---|---|
| 数据在哪 | 厂商服务器 | 本地或云 | **本地** |
| 会不会主动提醒 | 会（但要知道的事） | 你手动设的 | **会（从你的信息里自己看出来的）** |
| 能不能问历史 | 有限 | 不能 | **能（检索 + 工具）** |
| 能不能改 | 不能 | 不能 | **全部源码在手** |
| 代价 | 免费换数据 | 要你手动记 | **要自己折腾、能力不如大厂全** |
