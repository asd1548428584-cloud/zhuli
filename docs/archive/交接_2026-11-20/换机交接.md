## 0. 这是什么

一个跑在 Android 上的个人助理：把手机上的通知 / 分享 / 链接 / 图片 / 语音 / 视频 / 短信收进本地库，
做结构化提取，到点提醒，并能在对话里被问出来；支持云模型（敏感内容脱敏后才能出机）。

- 形态：Kotlin 逻辑层（`core/`，无 UI 依赖）+ 一个验收壳 App（`zhuli-assistant-step2-build`）
- 包名 `com.zhuli.app`，当前版本 **0.16-full / versionCode 16**，数据库 **v11**
- 目标机：努比亚 Z70 Ultra（NX733J，MyOS / Android 15/16，**无 GMS**）

## 2. 新电脑上怎么跑起来（5 步）

1. **装 JDK 17**（必须是 17，Kotlin/AGP 需要），解压 Gradle 8.11.1，装 Android SDK（platform 35 + build-tools 35.0.0）。
2. **解压搬家包**到一个固定目录，比如 `C:/gzq/zhuli/`。
3. **改 SDK 路径**：打开 `zhuli-assistant-step2-build\local.properties`，把
   `sdk.dir=D\:\\zhuli-dev\\android-sdk` 改成新机器上的 SDK 绝对路径（注意转义写法：`D\:\\path\\to\\sdk`）。
4. **构建**（命令行，Windows bash）：
   ```bash
   cd /c/gzq/zhuli/zhuli-assistant-step2-build
   export JAVA_HOME=/d/zhuli-dev/jdk-17.0.21+9      # 改成你的 JDK 路径
   /d/zhuli-dev/gradle-8.11.1/bin/gradle --no-daemon assembleDebug
   ```
   产物：`app\build\outputs\apk\debug\app-debug.apk`
5. **装机**：`adb install -r app-debug.apk`（**必须用同一份 keystore**，否则报 `INSTALL_FAILED_UPDATE_INCOMPATIBLE`；
   换签名要先 `adb uninstall com.zhuli.app`，数据会丢，先备份库）。

> 依赖说明：纯 AndroidX + ML Kit（中文 OCR 用 bundled 版，不走 Play 服务，因为目标机无 GMS）+ org.json。
> 没有引入 SQLCipher、MediaPipe、sherpa-onnx —— 这些是后续要加的，见第 7 节。

## 3. 手机上要给的授权（装完必做）

| 授权 | 在哪开 | 不开的后果 |
|---|---|---|
| 通知使用权 | 设置 → 通知 → 通知使用权 → zhuli助理 | 收不到任何通知（核心功能失效） |
| 短信权限（可选） | App 内「快递」→ 授权短信 | 只能靠 App 推送和分享，覆盖不到纯短信驿站 |
| 无障碍（可选） | 设置 → 无障碍 → zhuli助理 | 「屏幕操作」用不了（读屏 + 单步点击） |
| 定位（可选） | App 内 设置 → 到公司/到家提醒 | 地理围栏取件提醒用不了 |
| 电池白名单 / 自启动 | App 内「白名单引导」 | 后台被杀，提醒可能不响（MyOS 默认拦截 BOOT_COMPLETED） |

一次性授权命令（调试用）：
```bash
adb shell pm grant com.zhuli.app android.permission.READ_SMS
adb shell pm grant com.zhuli.app android.permission.ACCESS_FINE_LOCATION
```

## 5. 云端配置（当前在用）

- 服务商：基元律动 `https://tokenrhythm.studio/v1`（OpenAI 兼容 + Anthropic 兼容）
- 模型：`qwen3.8-flash`（`egg-alpha` 免费档实测返回 `HTTP 400 模型不可用`，别用）
- Key：存在手机 `shared_prefs/zhuli_secure.xml`（Keystore AES-GCM 加密），**不在代码里、不在本文档里**
- 重新填写：`adb shell am start -n com.zhuli.app/com.zhuli.app.MainActivity --es cloudbase 'https://tokenrhythm.studio/v1' --es cloudkey '你的Key' --es cloudmodel 'qwen3.8-flash'`
- 或 App 内「云设置」手填（已配置时 Key 留空表示不改）
- 隐私三级：非敏感原样上云 → 敏感**脱敏后**上云 → 证件/卡号/验证码**脱敏也不发**

## 6. 踩过的坑（换机器别再踩）

1. **签名**：换 keystore 会装不上，必须先卸载（丢数据，先备份库）。
2. **`adb logcat` 恒为空**：这台 ROM 限制，排障走「读库 + dumpsys + App 内面板」，别指望日志。
3. **读库方式**：`adb exec-out run-as com.zhuli.app cat databases/zhuli_inbox.db > x.db`
   ——**必须用 `exec-out`**，`adb shell cat` 会塞填充字节导致库损坏。
4. **手机没有 sqlite3**：改库流程是「pull → PC 上 Python 改 → base64 分块 `run-as sh -c 'echo .. | base64 -d >>'` 写回」。
5. **`am start --es q` 只在冷启动生效**：栈内要走 `onNewIntent`（已实现）；验收前必须**亮屏解锁**，息屏时进程冻结，看着像功能坏了（截图全黑且约 18KB 就是黑图）。
6. **adb 服务会反复重启**：`adb reverse` 映射随之丢失，验收脚本里每次先重建。
7. **`adb shell content query` 读短信**：能读；但 App 读要靠 `READ_SMS` 运行时权限。
8. **系统快递卡片读不到**：`com.zte.mifavor.suggest` 的出口受 `signature|privileged` 权限保护，别浪费时间。
9. **精确闹钟**：`setExactAndAllowWhileIdle` 在 MyOS 息屏被限流，必须用 `setAlarmClock`（状态栏会有闹钟图标，正常代价）。
10. **开机广播被拦**：MyOS 不投递 `BOOT_COMPLETED`，靠「打开 App 即 rescan」兜底，所以要引导电池白名单。
11. **午夜提醒别炸人**：23:00–07:00 提醒静音（可在设置关）。
12. **模型不支持 tools 时会 400**：已做自动降级纯聊天；换模型先用「出网记录」看 note 是否是 `tools`。

## 7. 下一步建议（按性价比）

1. **整库加密**：加 SQLCipher + 迁移（工作量中等，风险在迁移，务必先做备份）。
2. **端侧语音**：ModelStore 已能下 SenseVoice，接 sherpa-onnx 运行时即可解锁「本地转写」。
3. **参数化技能**：`skills` 表已在，接线约 2–3 小时；先定「规则冲突/优先级/误伤」的验收口径。
4. **每 App 通知开关 + 群聊摘要**：纯粹的功能补齐。

## 8. 数据与备份

- 库：`/data/data/com.zhuli.app/databases/zhuli_inbox.db`（v11，含 inbox / reminders / ledger / chat_log / cloud_log / skills / embeddings）
- 加密备份：App 内「数据安全 → 加密备份」，落到 `files/backups/*.json.enc`（Keystore 密钥，拔走也解不开）
- 明文导出：账本 CSV / 完整 JSON，走系统分享面板
- **换手机时**：先「加密备份」，新机装好后把 `backups/` 拷回去（或直接「数据安全 → 恢复最近备份」）
