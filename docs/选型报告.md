## 3. 技术栈分层定案（每层给出推荐 + 备选）

| 层 | 【推荐】 | 备选 | 备注 |
|---|---|---|---|
| 本地推理引擎 | **[定案] MLC-LLm 为唯一主力**（Vulkan GPU 全速吃满 Adreno 830，3B~7B Q4），Termux Ollama 仅作为薄兼容层兜底（保 API 生态，不跑重活） | 无（非必要不加第二引擎） | 用户拍板「选出最优的，充分利用 SoC」→ GPU 加速为主路径；Ollama 只是兜接口的壳，不当算力用。PoC 见 §5，token/s 不达标则回退讨论 |
| 语音 ASR | [sherpa-onnx](https://github.com/k2-fsa/sherpa-onnx)（离线流式，Android 原生支持，无需联网） | Whisper.cpp（Termux 内，可选） | 转写结果进入同一条提取流水线 |
| 图片 OCR | 本地 Tesseract（Termux）为主，敏感图强制本地 | PP-OCR 系（MNN/Paddle-Lite，按第 6 步调研定） | 支付账单截图走此通道入账 |
| 链接阅读 | 云端摘要 API（OpenAI 兼容 + 网页提取代理） | go-to-md 自托管（Termux 内）或本地 WebView | 已拍板：分享链接默认走云，敏感特征命中则只存不抓 |
| 快递查询 | [快递100 开放平台 API](https://api.kuaidi100.com/document/)（聚合多承运商；新账号赠约 50 次试用额度，够联调） | 单家官方 API / 降级为手动触发 | 需用户注册拿 Key |
| 数据库 | SQLite + **SQLCipher**（整库加密）+ FTS5 全文 + 向量检索插件 | — | 一个库装记忆/账本/聊天/实体归一 |
| 云 API | **OpenAI 兼容协议**：任意 BaseURL + Key 自填（DeepSeek/Kimi/Claude 中转均可接入，不改代码） | 直连单一厂商端点 | Key 只存 App 私有目录；不进日志不进代码库 |
| 日历 | CalendarContract 写入系统日历（双写，可关） | 仅助理内部提醒 | 已拍板「直接写系统日历」 |
| 备份恢复 | 本地加密 zip 包（手动 + 每周自动，一键恢复） | — | 已拍板不上云 |
| 开发环境 | 本机 Windows + Android Studio，真机 USB 调试（第 12 步真机硬验收前置） | Termux 脚本先行（PoC 用） | 第 5 步前先做 PoC 实测 |

### 6.4 本鱼的口味建议（仅供参考，不替你定）

- 试水：**M1**（最贴 SoC 的 Vulkan 路径）→ 再决定要不要叠 **M2**（双保险）。
- 中文任务（M1/M2/M3）>> M4/M5；Llama/Gemma 只在英文或极小内存占用场景有意义。
- 内存预算：日常留一档 ≤4B 级常驻即可；更大档位以 PoC 实测 tok/s 与温度为门槛。
