## 5. 执行中撞到的两个"可复现构建"缺口（已修一个、记录一个）

### 5.1 Gradle wrapper 指向官方源，本机不可达 · 已修

- 现象：`./gradlew` 卡在 `Downloading https://services.gradle.org/distributions/gradle-8.14-bin.zip`，9 分 7 秒后 `SocketTimeoutException`。
- 根因：`gradle/wrapper/gradle-wrapper.properties` 用官方地址；本机缓存里 `gradle-8.14-bin` 只有一个 13.6MB 的 `.part`（上次没下完）。
- 处置：`distributionUrl` 改为 `https://mirrors.cloud.tencent.com/gradle/gradle-8.14-bin.zip`（与旧壳工程一致，版本仍 8.14）。
- 本次实际执行用本地已解压的 `gradle-8.14`（`~/.gradle/wrapper/dists/gradle-8.14-all/...`），**没有验证镜像下载链路**——下次首次 `./gradlew` 会验证。

### 5.2 单测入口依赖前端构建 · 未修，已记录

- 现象：`:app:testDevDebugUnitTest` 触发 `:app:preBuild` → `:app:buildWebUi` → `cmd /c npm run build` → `'react-router' 不是内部或外部命令`，构建直接失败。
- 根因：`preBuild.dependsOn(buildWebUi, ":speech:downloadSherpaOnnxAar")`；`webUi/node_modules` 缺失。
- 临时办法：跑测试时加 `-x :app:buildWebUi -x :speech:downloadSherpaOnnxAar`。
- 建议（S5 再做）：给这两个依赖加一个 `-Pzhuli.skipHeavyAssets=true` 开关，让"只跑 JVM 测试"不必装前端工具链。
